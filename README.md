# Super Shop Management System

A desktop application for managing the daily work of a retail super shop. Built with **C# (WinForms)** and **SQL Server** as a university course project.

## Features
- User login
- Inventory tracking (add, update and view products)
- Billing
- Reports

## Tech Stack
- C# (.NET WinForms)
- Microsoft SQL Server
- Visual Studio

## How to Run
1. Clone the repository and open the solution file in Visual Studio.
2. Create the database in SQL Server and update the connection string in the project.
3. Build and run the project.
